# Disaster Response Training Game

An interactive disaster response training game developed using Python and Pygame. The application uses a story-based simulation to present an earthquake scenario and allows users to make decisions that lead to different outcomes.

## Project Overview

The project is designed as an educational simulation that demonstrates disaster-response awareness through interactive gameplay.

The current prototype presents a classroom earthquake scenario in which the player follows the story and makes a safety-related decision. Different choices lead to different outcomes.

## Features

- Story-based interactive gameplay
- Earthquake disaster-response scenario
- Decision-based gameplay with multiple outcomes
- Audio narration and sound effects
- Animated text and scene transitions
- Interactive buttons and menus
- Screen-shake effect during earthquake scenes
- Success and failure outcome screens
- Retry and menu navigation

## Technologies Used

- Python
- Pygame
- Object-Oriented Programming concepts
- Event-driven programming
- Game logic and interactive simulation
- Audio integration
- UI/UX design
